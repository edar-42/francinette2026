# push_swap tests (francinette)

The tests are written in python in `testers/push_swap/Fsoares.py`. They follow the push_swap
subject version 1.2 (strategies `--simple`, `--medium`, `--complex`, `--adaptive`, the `--bench`
mode, the disorder metric and the `checker` bonus).

The operations are validated with a checker written in python, so no `checker_linux` is needed.
